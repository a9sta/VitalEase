# 바이탈리즈 (VitalEase)

서울·인천·경기·부산은 **동·읍까지**, 대전·대구·울산과 지정 시·군은 **시군구까지** 쪽을 둔
출장마사지 홈타이 방문 안내 정적 사이트. 의존성 0, Node 표준 라이브러리만 쓴다.

```
npm run regions   # /tmp/hjd.geojson → data/regions.json  (행정동 경계 → 실측값)
npm run build     # → dist/
npm run check     # 14종 게이트
npm run simil     # 동·읍 쪽끼리 본문 겹침 비율
npm run serve     # 로컬 확인 (http://127.0.0.1:8080)
```

## 쪽 구성 (1,571쪽)

| 층 | 주소 | 수 |
|---|---|---|
| 대문 | `/` | 1 |
| 받는 자리 허브 | `/area/` | 1 |
| 시도 | `/{시도}/` | 15 |
| 시군구 | `/{시도}/{시군구}/` | 152 |
| **동·읍** | `/{시도}/{시군구}/{동}/` | **1,275** |
| 코스 | `/course/{코스}/` | 7 |
| 시도 × 코스 | `/{시도}/course/{코스}/` | 105 |
| 코스 허브·금액·이용안내·소개·약관·개인정보 | | 6 |
| 기록장 | `/magazine/` + 글 7 | 8 |
| 404 | `/404.html` (noindex·사이트맵 제외) | 1 |

### 일부러 만들지 않은 조합
- **동·읍 × 코스** — 1,275 × 7 = 8,925쪽. 자리가 달라져도 코스 설명이 같아 전부 얇은 조합 페이지가 된다.
- **면(面) 쪽** — 354곳. 집이 흩어져 있어 한 쪽을 채울 고유 사실이 안 나온다. 시군구 쪽에 이름만(접수는 받는다).
- **서브 지역의 동 쪽** — 깊이를 두 층으로 갈랐다. 동 이름은 시군구 쪽 목록에 있다.
- **옹진군·군위군** — 섬과 산골뿐이라 방문이 성립하지 않는다.

## 지역 데이터 — ★쓰는 사실은 '경계선의 길이와 모양'

`scripts/build-regions.mjs` 가 공개 행정동 경계(admdongkor `HangJeongDong_ver20260701`, CC BY 4.0)에서
아래 값을 **계산해서** 뽑는다. 손으로 적어 넣은 숫자가 없다.

| 값 | 어떻게 구하나 | 쪽에서 무엇을 말하나 |
|---|---|---|
| **둘레** | 바깥 고리를 따라 한 바퀴 돈 길이 | 길게 붙은 쪽일수록 접한 길이 많다 |
| **뭉침 정도** | 4πA/P² · 1에 가까울수록 동그람 | 들쭉날쭉하면 들어가는 길목이 여러 갈래 |
| **안쪽 깊이** | 테두리 안에 격자를 깔고 **경계에서 가장 멀리 들어간 점**까지의 거리 | 큰길에 닿은 뒤에도 남는 거리 = 도착 시각이 벌어지는 이유 |

앞선 다섯 사이트가 쓴 축(중심점 거리·방위·면적순위·끝과 끝 거리·맞닿음)과 겹치지 않는다.
맞닿음은 길을 거는 데만 쓰고 문장에서는 숫자로 내세우지 않는다.

실측 규모: 시도 15(동·읍까지 4) · 시군구 152 · 동 1,232 + 읍 43 = 1,275 · 면 354.

## 지키는 여덟 가지

1. **같은 주소 = 같은 HTML.** 무작위를 쓰지 않는다. 문장 고르기는 전부 주소 기반 해시다. 두 번 빌드해 `dist` 해시가 같은지 본다.
2. **전화번호는 `telBtn()` 으로만 찍는다.** 번호 옆에 '예약 문의'가 늘 붙는다. ★**'안심번호' 글자는 버튼에 넣지 않는다**(지시) — 번호의 성격은 약관 제2조·방침 3항에 남긴다.
3. **설명문은 100자 안쪽**(`clampDesc` 상한 100). 80자 안팎이 가장 안전하다.
4. **FAQ 는 `h3` 질문형 소제목으로.** ★순번은 h3 **밖에** 둔다 — 안에 넣으면 제목 글자가 "1바닥과…"가 되어 질문으로 읽히지 않는다.
5. **후기·체험담·평점·인물 사진을 싣지 않는다.** `aggregateRating` 도 넣지 않는다. 만 19세 미만은 받지 않는다.
6. **푸터에 AI 활용 고지**를 둔다.
7. **lastmod 는 본문 해시로 판정한다**(`data/lastmod.json`). ★이 파일은 **반드시 커밋**한다. 없이 깃에서 빌드하면 전 쪽이 매번 '오늘 수정'으로 밀려 거짓 신선도 신호가 된다.
8. **robots.txt 는 Yeti·Yeti-Mobile·`*` 세 그룹에 같은 규칙**을 적는다. `Crawl-delay` 는 적지 않는다.

## 색인

- 사이트맵 색인 + 조각(`core` + 시도 15) + `sitemap-latest.xml`(최근 14일 · 최대 2,000)
- `rss.xml` — `lastBuildDate` 는 **글 발행일**로 둔다(빌드 시각을 쓰면 같은 내용에도 파일이 매번 달라진다)
- `llms.txt` — 사실 요약과 자료 출처
- IndexNow 키는 `data/site.config.json` 의 `indexNowKey` 로 루트에 떨어진다. **키는 사이트마다 달라야 한다.**

## 호스팅 — Netlify

`https://vital-ease.netlify.app` (2026-10-12 배포).
★서브도메인 `vitalease` 는 남이 선점해 `vital-ease` 로 잡았다. Netlify 서브도메인은 전 세계 공용이다.

| | |
|---|---|
| 빌드 명령 | `npm run build` (= `node src/build.mjs`) |
| 출력 폴더 | `dist` |
| Node | 20 (`netlify.toml`) |

`dist/_headers` 와 `dist/_redirects` 를 빌드가 함께 떨어뜨린다 — Netlify 와 Cloudflare 가 같은 형식을 읽으므로
호스트를 옮겨도 빌드를 고칠 일이 없다. 빌드는 `URL`(Netlify) · `CF_PAGES_URL`(Cloudflare) · `SITE_URL` 순으로 본다.

★`data/site.config.json` 의 `siteUrl` 은 **배포 주소를 확인한 뒤** 그 값으로 바꾸고 다시 빌드한다.
canonical·사이트맵·RSS·llms.txt·OG 가 전부 이 값을 쓴다.
